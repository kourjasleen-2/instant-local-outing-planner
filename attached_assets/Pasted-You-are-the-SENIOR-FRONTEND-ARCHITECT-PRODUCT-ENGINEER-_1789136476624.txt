============================================================
PRODUCT DEFINITION
============================================================

GLIMMR takes:

- From
- To
- Available time
- Budget per person
- Number of people
- Transport
- Outing type / energy
- Optional preference

Then:

SEARCH
→ generate plans
→ user selects a plan
→ user can edit / replace / delete / add
→ system recalculates
→ user can regenerate
→ user can start outing

The plan is a LIVING PLAN, not a static page.

============================================================

============================================================

These actions MUST remain conceptually different.

1. REGENERATE
Meaning:
"Give me a different overall plan."

Preserve:
- location
- destination
- time
- budget
- people
- transport
- outing type
- important preferences

- recommended combinations

2. EDIT
Meaning:
"Change this particular part of the plan."

3. REPLACE
Meaning:
"Replace this particular place with another suitable place."

4. DELETE
Meaning:
"Remove this stop."

Then recalculate:
- total cost
- group total
- total duration
- travel time
- route distance
- feasibility

5. ADD
Meaning:

Then recalculate:
- total cost
