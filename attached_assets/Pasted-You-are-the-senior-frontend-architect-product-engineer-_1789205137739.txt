==================================================
CURRENT GLIMMR PRODUCT
==================================================

Glimmr is a context-aware local outing planner.

User provides:
- From
- To
- Time available
- Budget per person
- Number of people
- Transport
- Outing type / energy
- Optional natural-language preference

Glimmr generates a personalized outing plan.

The plan is a LIVING PLAN.

The user can:
- View
- Edit
- Replace
- Delete
- Add
- Regenerate

Whenever the plan changes, the system conceptually recalculates:
- cost per person
- group total
- total duration
- travel time
- route distance
- feasibility

Core loop:

INPUT
→ SEARCH
→ PLANS
→ VIEW PLAN
→ EDIT / REPLACE / DELETE / ADD
→ RECALCULATE
→ UPDATED PLAN
→ START OUTING
