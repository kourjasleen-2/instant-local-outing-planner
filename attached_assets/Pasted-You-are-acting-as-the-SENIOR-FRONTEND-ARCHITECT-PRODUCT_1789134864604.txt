==================================================
PRODUCT CONTEXT
==================================================

GLIMMR is a context-aware local outing planner.

The user provides:
- From location
- To location
- Available time
- Budget per person
- Number of people
- Transport mode
- Outing type / energy
- Optional natural-language preference

The product generates outing plans based on the user's situation.

The user must then be able to dynamically modify the plan.

Core product loop:

USER INPUT
→ PLAN
→ EDIT
→ ADD
→ DELETE
→ REGENERATE
→ RECALCULATE
→ GO

The plan is NOT static.

Whenever the plan changes, the system must conceptually support recalculation of:
- total cost
- group cost
- duration
- travel time
- distance
- route
- feasibility
